# Guru & Jana Website

A professional corporate website recreation for Guru & Jana Chartered Accountants built with React, Vite, TypeScript and Tailwind CSS.

## Features

- Responsive multi-page website
- Services directory and detail pages
- Insights listing and article pages
- Careers section with open roles
- Contact form with validation
- Accessible UI and responsive design
- SEO metadata and modern layout

## Technology stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- React Router v6
- Lucide React icons
- Framer Motion (planned for subtle animation)
- react-helmet-async for metadata

## Folder structure

```
src/
  assets/
  components/
  data/
  layouts/
  pages/
  App.tsx
  main.tsx
  index.css
```

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production build

```bash
npm run build
```

## Preview build

```bash
npm run preview
```

## Environment variables

Copy `.env.example` to `.env` and update values as needed.
